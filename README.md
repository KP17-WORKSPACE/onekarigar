### Prerequisites
- Web hosting with Apache/LiteSpeed (for .htaccess)
- SSL certificate (HTTPS)
- Domain name (onekarigar.com)

### Setup Instructions

1. **Upload Files**
   ```bash
   # Upload all files to your web server
   ```

2. **Create Required Images**
   - OG Image: 1200x630px → `assets/images/og-image.jpg`
   - Favicon: Multiple sizes → `assets/images/favicon.ico`
   - Use: https://realfavicongenerator.net/

3. **Google Search Console**
   - Sign up at: https://search.google.com/search-console
   - Add property: www.onekarigar.com
   - Submit sitemap: `https://www.onekarigar.com/sitemap.xml`

4. **Google Business Profile**
   - Create listing: https://business.google.com
   - Complete 100% of profile

5. **Analytics Setup**
   - Install Google Analytics
   - Install Google Tag Manager (optional)
